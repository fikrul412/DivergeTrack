# DivergeTrack

DivergeTrack is an To do List app with Node Graph based item. With this app you can see the bigger
picture of you to do list or project tasks and get deeper insight.

## Features

### Branch
- Branch is like a project folder where you put you to do item as node from the main branch
- Node is a single to do item that can be connected to each other
- Node data, note data is consist of: Problem, Discovery, Note, Next action

### Add new Node
- We can add a new node by selecting the main branch first, then click new Node and connect the
item to the main branch or existing node

### Add node automatically
- It's the same as before, but you just write a sentence and the AI will decide all the node
data and connect it to he most appropriate node based on your sentence
